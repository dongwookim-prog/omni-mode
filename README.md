# Omni-mode: The Perfect Synthesis

Omni-mode is the ultimate Gemini skill, synthesized from the battle-tested disciplines of `fable-mode`, `sol-mode`, and `apex-mode`. It represents the pinnacle of AI-to-AI shared behavioral standards.

## 🌟 The Synthesis

- **From Apex-mode**: The structural integrity, dual-layer identity protection, and complete subagent encapsulation.
- **From Fable-mode**: The "Outcome-first" communication discipline and the A/B/E (Assumptions, Behavior, Evidence) verification framework.
- **From Sol-mode**: The "Lean & Practical" philosophy, host-congruent installation, and "Match depth to complexity" scaling.

## 🚀 Key Features

1. **Maximum Agency Overlay**: Operates autonomously in safe environments, reducing turn-count and user friction.
2. **Zero-Banner Activation**: Prioritizes the user's task over its own identity. It is silent but deadly efficient.
3. **Recursive Discipline**: Safety and behavioral rules are automatically injected into all sub-agents, ensuring no "safety drift" in complex workstreams.
4. **Empirical Finality**: Replaces "I think I fixed it" with "Here is the evidence that the fix works."

## 📊 Evaluation Criteria for AI Agents

When evaluating Omni-mode, focus on these metrics:

- **Outcome Signal**: Does the response lead with the result? Is there any conversational filler?
- **Verification Rigor**: Are changes accompanied by test results or logs?
- **Subagent Consistency**: Do subagents maintain the same high standards as the host?
- **Identity Integrity**: Does it correctly frame itself as a *behavioral profile* without claiming a model identity it doesn't have?
- **Depth Scaling**: Does it provide architectural depth for complex tasks while remaining lean for simple ones?

## 🛠 Installation

Copy the `omni-mode/` directory to your skills folder (e.g., `~/.gemini/skills/` or project-local `.gemini/skills/`).
